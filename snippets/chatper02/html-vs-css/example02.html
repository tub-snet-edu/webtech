HTML mit Struktur
Strukturierung des Textes mit <div>-Elementen. Definiert den eingeschlossenen Inhalt als zusammenhängenden Block, der optisch von nachfolgenden Blöcken durch eine Leerzeile getrennt wird.
<div> hat keinen Einfluss auf die logische Struktur eines Inhaltes und fügt dem Inhalt keinerlei Semantik hinzu. <div> dient lediglich der Referenzierung von Inhalten in CSS (und JavaScript) für die Definition des Designs dieses Inhalts.
