Markup-Sprachen HTML ohne Struktur Leerzeilen im Quelltext verschwinden in der Darstellung. Mehrere Leerzeichen werden auf ein Leerzeichen reduziert. Beispiel enthält keine Struktur, vergleichbar mit einem Buch, welches von der ersten bis zur letzten Seite den Text ohne Kapitel, Überschriften, Seitenzahlen, Absatz- und Seitenumbrüchen enthält. Zweck von HTML ist die Strukturierung (Annotation, Auszeichnung) von Inhalten und Texten, um sie in eine semantische Form zu Strukturierung geschieht mit Hilfe von HTML-Elementen
